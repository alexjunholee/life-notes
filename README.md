# Life Notes

인생은 선택의 연속이고 우리는 행복해지고 싶다. 어떤 선택을 할 것인가?
한번 전략적으로 접근해 보자.

이 책은 진로를 정하지 못한 공학계열 학부생과 초기 경력 엔지니어를 위한
자료 기반 요약 안내서다. 정답인 직업을 골라 주는 대신, 행복을 이루는 조건을
나누고 모르는 것을 확인한 뒤 한동안 실행하고 다시 판단하는 방법을 다룬다.
연구직은 제품, 인프라, 현장, 기술 관리와 나란히 놓인 여러 경로 가운데
하나다.

## 필요한 곳부터 읽기

- 전공과 진로를 처음 고르는 중이라면 1–8장부터 읽는다.
- 엔지니어의 실제 업무와 입사 조건을 비교하려면 9–14장을 본다.
- 역량, 제안, 관계를 통해 다음 선택지를 늘리고 싶다면 15–18장이 이어진다.
- 입사 뒤 남을지 옮길지 고민한다면 19–21장을 먼저 읽어도 된다.
- 번아웃과 정신건강, 일 밖의 생활은 22–24장에서 다룬다.

각 장 끝에는 실제로 사용한 논문과 공공기관 자료를 붙였다. 연구 결과를
소개할 때에는 연구 대상과 설계가 허용하는 범위도 본문에 함께 적었다. 23장의
대한민국 위기지원 정보는 2026년 8월 31일 공식 페이지에서 확인했다.
