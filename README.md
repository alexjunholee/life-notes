# Life Notes

인생은 선택의 연속이고, 기왕이면 잘 선택해 행복하게 살고 싶다. 그렇다고 감이나 막연한 기대에만 기대기에는 진로와 일의 변수가 너무 많다. 한 번쯤 한 걸음 물러서서 선택을 전략적으로 따져 볼 필요가 있다.

이 책은 아직 진로를 정하지 못한 공학계열 학부생과 사회에 막 발을 디딘 초기 경력 엔지니어를 위해 자료를 바탕으로 정리한 안내서다. 정답처럼 보이는 직업 하나를 콕 집어 추천하는 대신, 행복을 떠받치는 여러 조건을 나누어 살펴보고, 모르는 부분을 몸으로 확인한 뒤, 일정 기간 실행해 보고 다시 판단하는 기준을 다룬다. 연구직 역시 제품 개발, 인프라, 현장 엔지니어링, 기술 관리와 나란히 놓인 여러 선택지 가운데 하나로 다룬다.

## 필요한 곳부터 읽기

- 전공과 진로를 처음 고르는 중이라면 1–8장부터 읽는다.
- 엔지니어의 실제 업무와 입사 조건을 비교하려면 9–14장을 본다.
- 역량, 제안, 관계로 다음 선택지를 늘리고 싶다면 15–18장이 이어진다.
- 입사 뒤 남을지 옮길지 고민한다면 19–21장을 먼저 읽어도 된다.
- 번아웃과 정신건강, 일 밖의 생활은 22–24장에서 다룬다.

각 장 끝에는 실제로 사용한 논문과 공공기관 자료를 붙였다. 연구 결과를
소개할 때는 연구 대상과 설계가 허용하는 범위도 본문에 함께 적었다. 23장의
대한민국 위기지원 정보는 2026년 8월 31일 공식 페이지에서 확인했다.
